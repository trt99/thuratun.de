Warum das zähltFürs Testen

Ein fehlgeschlagener Test ist nicht immer ein Bug im Code.

Manchmal ist es ein abgelaufenes Zertifikat, ein gesperrter Port, eine fehlende Berechtigung, ein Netzwerkproblem oder ein Problem mit dem Betriebssystem. Das prüfe ich aus Gewohnheit zuerst. Was ich als Bug melde, ist also ein Bug, und alles andere bekommt einen Hinweis, wo das eigentliche Problem liegt.
